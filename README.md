# Python Practice Projects

A collection of practice projects for learning NumPy, Matplotlib, and algorithms.
The goal is to build enough foundation to use Python independently.

## Projects

| Project | File | What I learned |
|---------|------|----------------|
| P1 - Basic Charts | Graph_compare.py | plt.plot, plt.bar, plt.hist, plt.scatter |
| P3 - Grid Visualization | imshow_grid.py | imshow, mcolors, ListedColormap, vmin/vmax |
| P4 - Animation of Graph | animation.py | FuncAnimation, update, frame |

## How to Run

**macOS / Linux**
```bash
python3 Graph_compare.py
python3 imshow_grid.py
python3 animation.py
```

**Windows**
```bash
python Graph_compare.py
python imshow_grid.py
python animation.py
```
